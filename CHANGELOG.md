# Changelog

## 1.0.1 — 2026-10-08

- Checked on game v0.29.1 (1.0.0 also works)
- If a future game update breaks the mod, the mod turns itself off instead of stopping the game from starting

## 1.0.0 — 2026-09-14

- Pins the position of icons in the inventory
- R-Click a slot to pin or unpin
- Drag and drop to swap slots, pins included
- Marker on pinned slots, `0` shown at zero stock
