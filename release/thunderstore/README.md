# LWF Pinned Slots

Pins item icons to fixed places in the inventory of **Lazy Witch's Factory**.

## Pin item icons in place

- Pins the position of icons in the inventory
- A pinned slot shows a marker
- At zero stock the slot shows a dimmed icon and `0`

![Pinned slots](https://raw.githubusercontent.com/KiyonakaNata/lwf-pinned-slots/main/img/pin-keep.webp)

## Pin / unpin

- R-Click a slot → pin the item in it
- R-Click a pinned slot → unpin

![Pin and unpin](https://raw.githubusercontent.com/KiyonakaNata/lwf-pinned-slots/main/img/pin-toggle.webp)

## Swap

- Drag a slot onto another slot → item and pin move together
- An item in the target slot swaps places

---

Settings: `BepInEx/config/kiyonakanata.lwfpinnedslots.cfg`. Full documentation: [GitHub](https://github.com/KiyonakaNata/lwf-pinned-slots).

Tested on Lazy Witch's Factory **ver 0.29.1**. Unofficial mod, not supported by the developer.
