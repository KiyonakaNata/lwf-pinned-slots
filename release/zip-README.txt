LWF Pinned Slots
Lazy Witch's Factory の所持品欄のアイコンの場所を固定する MOD
Pins item icons to fixed places in the inventory of Lazy Witch's Factory

────────────────────────────────
入れかた
────────────────────────────────

1. BepInEx 5 を落として、ゲームのフォルダ
   （LazyWitchsFactory.exe と同じ場所）へ展開する

     https://github.com/BepInEx/BepInEx/releases
     BepInEx_win_x64_5.4.x.zip

2. 一度ゲームを起動して終了すると、BepInEx/plugins などが作られる

3. LwfPinnedSlots.dll を BepInEx/plugins/ に入れる

4. ゲームを起動する。所持品欄のセルを右クリックすると印が付く

MOD管理ソフトを使うなら Thunderstore から

     https://thunderstore.io/c/lazy-witchs-factory/p/KiyonakaNata/LwfPinnedSlots/

────────────────────────────────
使いかた
────────────────────────────────

セルを右クリック → その場所に固定。もう一度で解除
セルをドラッグして別のセルに落とす → 入れ替え

────────────────────────────────
消しかた
────────────────────────────────

BepInEx/plugins/LwfPinnedSlots.dll を消す
設定も消すなら BepInEx/config/kiyonakanata.lwfpinnedslots.cfg

────────────────────────────────

Lazy Witch's Factory ver 0.27.0 / BepInEx 5.4.23.5 で確認
非公式のMOD、公式のサポート対象外

説明と画面は GitHub

     https://github.com/KiyonakaNata/lwf-pinned-slots

English
────────────────────────────────

Install

1. Unpack BepInEx 5 (win x64) into the game folder

     https://github.com/BepInEx/BepInEx/releases

2. Start the game once and quit, so BepInEx/plugins is created

3. Put LwfPinnedSlots.dll into BepInEx/plugins/

4. Start the game. R-Click a slot in the inventory and a marker appears

With a mod manager, install from Thunderstore

     https://thunderstore.io/c/lazy-witchs-factory/p/KiyonakaNata/LwfPinnedSlots/

Use

R-Click a slot to pin the item in it. R-Click again to unpin.
Drag a slot onto another slot to swap.

Remove

Delete BepInEx/plugins/LwfPinnedSlots.dll
Delete BepInEx/config/kiyonakanata.lwfpinnedslots.cfg to drop the settings

Tested with Lazy Witch's Factory ver 0.27.0 / BepInEx 5.4.23.5
Unofficial mod, not supported by the developer

     https://github.com/KiyonakaNata/lwf-pinned-slots
